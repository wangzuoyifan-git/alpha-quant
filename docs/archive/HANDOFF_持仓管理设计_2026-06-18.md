## 二、下一阶段任务：持仓管理模块（本文档核心）

### 2.1 动机：当前 L3 只做了"进场"，没做"持仓管理"

当前每个 L3 策略的 `generate_signals()` 只回答"现在该不该买"（进场信号），
**没有回答**：买入后跌到哪止损、涨到哪止盈、止损位随价格如何移动。

当前 `trader/assistant.py` 用**固定百分比**（成本-7%止损、成本+20%止盈）粗暴补上，
但这是风控层硬加的，不是策略自己的逻辑，且"一刀切"不合理：
- 突破策略应紧止损（假突破要快走）
- 趋势策略应宽止损（让利润奔跑）
- 价值策略不该看价格止损（该看估值修复）

### 2.2 设计共识（已与用户讨论确认）

**核心理念：进场归属（entry attribution）与持仓管理（position management）解耦。**

**B方案（用户选定的长期方案）**：让每个 L3 策略输出自己的支撑/压力位和出场逻辑，
扩展 `Signal.extra` 字段：

```python
Signal(
    ..., 
    extra={
        "stop_loss": 385.0,        # 策略认为的止损位
        "take_profit": 440.0,      # 止盈位
        "support": 385.0,          # 当前支撑位
        "resistance": 440.0,       # 当前压力位
        "exit_logic": "trail_ma20",# 退出逻辑类型
        "atr": 12.5,               # 当前ATR
    }
)
```

下游消费：
1. `portfolio` 命令：读策略给的支撑/压力位（而非固定百分比）
2. 回测引擎：用策略自己的止损逻辑回测（出场真实化）
3. 风控层：固定百分比降级为兜底（策略没给时才用）

### 2.3 用户提出的两个深化需求（关键，必须纳入设计）

**需求1：手动持仓/外部标的（无进场标注）如何纳入管理？**

用户有存量持仓和自己选的标的，没有"哪个策略买的"标注，但也想让系统管理止损止盈。
设计为三层降级：
- **方案B（推荐做底层）**：portfolio.json 加 `style` 字段声明持仓性质
  ```json
  {"code":"601899","name":"紫金矿业","cost":28.55,"shares":5000,"style":"value"}
  ```
  按 style 选对应出场逻辑（value→估值止盈，trend→移动止损）
- **方案C（辅助，自动推断）**：对持仓反向运行所有L3策略，看哪个策略"认领"这只票
  （portfolio命令现在已经在跑所有策略，可复用）
- **方案A（兜底）**：未声明时用通用规则（ATR动态止损 + 关键支撑压力位）

**需求2：止损止盈 ≠ 支撑压力，要结合风险承受能力 + 分批仓位建议**

用户理解正确，触及量化持仓管理核心。设计要点：
- **支撑/压力位 = 市场结构（输入）；止损/止盈点 = 决策（输出）**，两者不等价
  （如支撑¥380，但止损可能设¥375给假突破留空间）
- **基于风险的仓位管理（risk-based position sizing）**：
  ```
  单笔最大亏损 = 总资金 × 单笔风险比例（如1~2%）
  仓位股数 = 单笔最大亏损 / (进场价 - 止损价)
  ```
  止损越近可买越多（风险恒定）——把支撑位+风险承受+仓位三者统一
- **分批加减仓（scaling in/out）**：
  - 金字塔加仓（趋势确认后加，越加越少）
  - 分批止盈（到压力位卖1/3，再涨卖1/3，剩余移动止损跟随）
  - 分批止损（跌破支撑先减半，确认再清）
- **最终输出形态**：不是单一止损价，而是一张**分级操作表**：

  | 价位 | 类型 | 操作 | 仓位变化 | 依据 |
  |---|---|---|---|---|
  | ¥120 | 压力位 | 止盈 | -33% | 前高+估值偏高 |
  | ¥97 | 近支撑 | 减仓 | -50% | 跌破短期均线 |
  | ¥93 | 强支撑 | 清仓 | -100% | 跌破趋势线+ATR止损 |

### 2.4 业界最佳实践参考（供新session展开）

**止损止盈方法（技术面）**：
- ATR动态止损（最广泛）：止损距离 = ATR(14) × 2~3倍，自适应波动率
- Supertrend：ATR延伸带趋势方向，下轨随价格上移=移动止损（即"趋势性支撑点"）
- 前期关键价位：近N日摆动高低点、布林带下轨、成交量价格分布(VolumeProfile，机构最重视)
- 斐波那契回撤：A股有效性一般，散户参考

**止损止盈方法（基本面，适合配置仓）**：
- PE历史分位>75%开始减仓
- 基本面恶化（ROE大幅下降）触发

**按持仓类型匹配**：
| 持仓类型 | 止损方法 | 止盈方法 |
|---|---|---|
| 交易仓（技术入场） | ATR动态止损 + 近期摆动低点 | Supertrend上轨/近期压力高点 |
| 配置仓（基本面入场） | 基本面恶化或ATR宽止损 | PE历史分位>75%减仓 |
