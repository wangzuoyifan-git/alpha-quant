## 二、关键设计决策记录

1. **B 方案**：compute_exit_levels 在 BaseStrategy 有默认 ATR 实现（向后兼容），各策略可重写
2. **复权口径**：策略计算用 hfq；展示换算回不复权；进场价用"当前 hfq 价"（不用成本/adj_factor 推算，避免历史因子错位）
3. **配置仓 stop_loss=0**：position_manager 和回测遇到 stop_loss=0 跳过价格止损
4. **回测出场等价**：建仓时调一次 compute_exit_levels，后续每日只做轻量 check_exit_triggered，移动止损每日 update
5. **委托价逻辑**：不同信号类型有不同偏移（涨停打板 / 突破溢价 / 均值回归限价 / 配置仓不追）

## 三、已知限制（不是 bug，是设计取舍）

| 限制 | 说明 |
|---|---|
| 回测出场基于收盘价 | 止损触发用日收盘判断，非日内最高/最低，比实际交易稍滞后；日线回测行业惯例 |
| exit-levels 全市场扫描无精确股数 | 无 df 时用 7% 估算止损距，标注"(估)"；--codes 模式有精确值 |
| signal.extra 不含 exit_levels | generate_signals 不自动写入，按需在 portfolio/exit-levels/backtest 时计算（避免扫描耗时增加） |
| Volume Profile 未实现 | 依赖分钟线数据，当前未接入 |
