## 一、本日新增/变更功能

### 1.1 L3 策略正交化改造（docs/strategy.md 第〇章框架）

**设计原则落地：少而精、正交、上层可选**

交易仓（4个，L3-A）：

| 策略 | 正交维度 | 主要升级 |
|---|---|---|
| `ma_cross` v2 | 趋势跟踪 | ADX≥20 趋势强度过滤 + 资金流内置确认（吸收 money_flow） |
| `macd_rsi` v2 | 均值回归 | RSI 阈值 35→40 + RSI 底背离 + 强制确认门槛；修复死叉条件 bug |
| `vol_price_breakout` v2 | 突破 | 缩量蓄力确认 + ATR 标准化 + SELL 语义明确（scan_sell 参数） |
| `etf_momentum` v2 | ETF 轮动 | 绝对动量过滤 + 仅适用 ETF（applicable_asset_types=["etf"]） |

配置仓（3个，L3-B，Fama-French 正交）：

| 策略 | 正交维度 | 主要升级 |
|---|---|---|
| `fundamental_value` v3 | 质量（Quality） | PE 历史分位过滤（≤60分位）替代固定 PE≤30 |
| `deep_value` v2 | 价值（Value） | 金融/地产行业排除 + 股息率验证 + 连续2季盈利 |
| `growth_pick` v2 | 成长（Growth） | 净资产增长双验证 + PEG≤1.5 控估值 |

`money_flow`：从注册表降级，能力并入 `ma_cross` 过滤层（类保留供回测历史兼容）。

`BaseStrategy` 新增 `applicable_asset_types` 字段，scanner 和 scan 命令均做资产类型过滤。

### 1.2 回测引擎升级

- `Backtester.run()` 新增 `asset_type` 参数，支持 ETF 回测
- `BacktestResult` 新增 `benchmark_return` / `alpha` / `beta` 字段（vs 沪深300）
- 夏普比率修正为已扣无风险利率（2%）
- `summary()` 有基准数据时展示「基准收益/超额收益(alpha)/beta」

### 1.3 L2 行业→行业 ETF 映射

**ETF 配置决策权从 L3 上移到 L2**

- `data/store_meta.py`：新增 `SW_L1_ETF_MAP`（31个申万L1→代表性行业ETF映射表）和 `get_industry_etfs()`
- `agents/industry_agent.py`：`evaluate_industry_rotation` 输出新增 `etf_candidates` 字段
- `engine/scanner.py`：`scan()` 新增 `etf_whitelist` 参数，ETF 扫描仅限 L2 选中行业的 ETF
- 完整透传链路：L2 产出 → decision_context → scan_node → run_scan → ScanEngine

### 1.4 风控扩展（RC7）

- `data/store_events.py`：新增 `has_pledge_risk(code, threshold=50.0)`，读最新 `pledge` 事件的 `pledge_ratio`
- `trader/assistant.py`：RC7 扩展到高比例股权质押（BUY 拦截），`risk_flags` 细分为 `RC7_reduce` / `RC7_pledge`
- WATCH 信号事件风险标注：有减持/质押风险时写入 `sig.extra["event_warnings"]`，打标不拦截

### 1.5 scan 命令 L3 独立验证能力

```bash
# 新增参数
--strategy   只运行指定策略（不传=全部）
--codes      指定股票代码或名称（精确/模糊匹配，多候选时列出）
--industries 指定申万行业名称或代码（精确/模糊匹配）
--industry-level L1/L2/L3（默认L1）
```

- 输出按 BUY/SELL/WATCH 分组展示，含持仓类型（trading/config）、触发原因、事件警告列
- `--codes` 和 `--industries` 均支持中文名称输入，模糊匹配
- 资金流显示优化：小额改用万元单位，数据超过5天未更新时标注 `(数据较旧)`

### 1.6 Bug 修复

| Bug | 修复 |
|---|---|
| `etf_momentum` 在股票扫描时运行，产生 WATCH+trading 噪音信号 | `applicable_asset_types=["etf"]`，scanner 和 scan 命令均过滤 |
| `macd_rsi` 死叉条件写错 `last_dif < prev_dea`（应为 `last_dea`） | 修正为 `last_dif < last_dea` |
| `ma_cross` 资金流为负时 reason 列无显示（误以为0） | 负值和缺失均写入 reason，小额换万元单位 |
