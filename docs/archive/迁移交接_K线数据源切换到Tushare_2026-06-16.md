# K线数据源迁移交接文档：baostock → tushare

> 创建日期：2026-06-16
> 适用 Session：下一个专门负责数据迁移的 Session
> 背景：当前主链路 K 线下载（downloader.py）走 baostock，已付费的 tushare 反而只用在边缘。
> 目标：将 stock/index/ETF 日线主下载链路全部切换至 tushare，数据格式保持向后兼容。

---

## 一、背景与动机

| 现状 | 问题 |
|---|---|
| 每日下载主源：baostock（免费，adjustflag=1 后复权） | 免费源限流/连接不稳定，扫描时联网兜底频繁堵死 |
| tushare：已付费，积分充足，只用于资金流/行业分类 | 最稳定的源反而没用在最核心的 K 线上 |
| fetcher.get_daily 兜底已改为 tushare 优先（2026-06-16 fix） | 但主下载链路 downloader.py 未改，口径碎片化 |

迁移后的目标状态：
- `update` / `init` 主下载：tushare `pro_bar`（qfq/hfq 均可，对齐当前 hfq）
- ETF：tushare `fund_nav_em` 或 `pro_bar`（目前走 akshare，ETF 不复权）
- index：tushare `index_daily`
- 格式：parquet schema 保持不变，所有下游代码（strategies/engine/backtest）**零改动**

## 二、当前本地数据 Schema（必须完整保留）

以下是 `store.save` 写入 parquet 的字段，迁移后必须保持相同 index name 和 columns。

### stock（data/market/cn/stock/<code>.parquet）

```
index:   date（DatetimeIndex）
columns: open, high, low, close, preclose, volume, amount, turn,
         trade_status, pct_chg, pe_ttm, pb_mrq, ps_ttm, pcf_ttm, is_st
单位:    volume=股（baostock 原始），amount=元，价格=后复权
复权:    baostock adjustflag="1"（后复权 hfq）
```

重要字段说明：
- `volume`：单位**股**（baostock 原始）。tushare `vol` 单位是**手**，写入前必须 ×100
- `amount`：单位**元**。tushare `amount` 单位是**千元**，写入前必须 ×1000
- `trade_status`：0=停牌，1=交易（baostock `tradestatus`）。tushare 需要从 `trade_cal` 或 `suspend_d` 推导，或对缺失行标注为 1
- `is_st`：0/1 整数（baostock `isST`）。tushare `namechange` 或 `stock_basic` 的 `list_status` 推导
- `pe_ttm`, `pb_mrq`, `ps_ttm`, `pcf_ttm`：估值字段。tushare `daily_basic` 接口：`pe_ttm`, `pb`, `ps_ttm`, `pcf_ncf_ttm`
- `preclose`：前收盘价。tushare `daily` 有 `pre_close` 字段，pro_bar 需要自行 shift 计算
- `turn`：换手率。tushare `daily_basic` 的 `turnover_rate`

### index（data/market/cn/index/<code>.parquet）

```
columns: open, high, low, close, preclose, volume, amount, pct_chg
tushare 接口: pro.index_daily(ts_code=..., start_date=..., end_date=...)
注意: 上证综指=000001.SH，沪深300=000300.SH，需带交易所后缀
```

### ETF（data/market/cn/etf/<code>.parquet）

```
columns: open, high, low, close, preclose, volume, amount, pct_chg
复权: 不复权（baostock adjustflag="3"）
tushare 接口: pro_bar(ts_code=..., asset='FD', adj=None) 或 fund_nav_em
```

## 三、tushare 接口映射

| 数据 | tushare 接口 | 关键参数 | 频率限制 |
|---|---|---|---|
| 股票日线（复权） | `ts.pro_bar(ts_code, adj='hfq', start_date, end_date)` | adj='hfq' | 每分钟约200次 |
| 股票日线估值字段 | `pro.daily_basic(ts_code, start_date, end_date)` | 含 pe_ttm/pb/turn | 每分钟约500次 |
| 指数日线 | `pro.index_daily(ts_code, start_date, end_date)` | ts_code 需带.SH/.SZ | 每分钟约200次 |
| ETF 日线 | `ts.pro_bar(ts_code, asset='FD', adj=None, ...)` | asset='FD' | 每分钟约200次 |
| 交易日历 | `pro.trade_cal(exchange='SSE', start_date, end_date)` | is_open=1 | 充足 |
| 股票基本信息 | `pro.stock_basic(exchange='', list_status='L')` | 含 ts_code/name/list_date | 充足 |

tushare ts_code 格式规则：
- 沪市（6开头）→ `<code>.SH`（如 `600519.SH`）
- 深市/创业板/科创板 → `<code>.SZ`（如 `000001.SZ`，`300750.SZ`，`688981.SZ`）
- 北交所（8/9开头） → `<code>.BJ`（如 `830799.BJ`）

## 四、单位和字段转换对照表（tushare → 本地 schema）

```python
# pro_bar 字段映射
rename_map = {
    "trade_date": "date",
    "vol":        "volume",    # 手 → 股：×100
    "pre_close":  "preclose",
    "pct_chg":    "pct_chg",
}

# 单位换算（必须在写入 parquet 之前执行）
df["volume"] = df["volume"] * 100        # 手 → 股
df["amount"] = df["amount"] * 1000       # 千元 → 元

# daily_basic 字段映射（估值字段 merge 进来）
rename_basic = {
    "trade_date":     "date",
    "pe_ttm":         "pe_ttm",
    "pb":             "pb_mrq",
    "ps_ttm":         "ps_ttm",
    "pcf_ncf_ttm":    "pcf_ttm",
    "turnover_rate":  "turn",
}

# trade_status：pro_bar 无停牌字段，全量设为 1；
# 若要精确，用 pro.suspend_d(ts_code, suspend_type='S') 覆写为 0
```

## 六、已知风险与处理方案

| 风险 | 说明 | 处理 |
|---|---|---|
| 复权基准不同 | baostock hfq 与 tushare hfq 基准日不同，close 绝对值不同（约几倍差距） | **正常现象**，pct_chg 涨跌幅一致，策略用相对指标不受影响；旧数据保留在 `data/market_baostock/` 作为交叉验证基线，不再用于回测比较 |
| is_st 精度 | tushare stock_basic 有 `list_status`，但历史 ST 状态需用 `namechange` 推导 | 暂用 stock_basic 近似，精度略低，后续可完善 |
| trade_status 缺失 | pro_bar 无停牌标志 | 全量置 1，scanner 的 S4 停牌过滤仍可用（会少过滤停牌股，但影响小） |
| tushare 积分 | 全量下载 5208×N 次 pro_bar 调用，消耗积分较多 | 先查剩余积分：`pro.query('user_basic')['remain_time']`；分批执行 |
| 北交所代码 | 920xxx 系列 tushare 用 .BJ 后缀 | downloader 需识别 8/9 开头代码映射 .BJ |
| 历史信号/回测结果 | price 字段绝对值基于旧 baostock 复权，迁移后不再对应新数据 | 旧信号文件（data/processed/signals_*.json）保留但标记为 baostock 口径，新信号自然用新数据生成 |

## 九、双源并存与交叉验证目录约定

迁移完成后，两套数据并存，**主链路优先使用 tushare 新数据**：

```
data/market/          ← 主数据（tushare 口径，store.load 默认读此处）
data/market_baostock/ ← baostock 历史基线（交叉验证专用，只读，不更新）
```

**读取约定：**
```python
import data.store as store
import pandas as pd

# 主数据（tushare，日常使用）
df_new = store.load("600519")

# baostock 基线（交叉验证专用）
from pathlib import Path
df_old = pd.read_parquet(
    Path("data/market_baostock/cn/stock/600519.parquet"),
    engine="pyarrow"
)
```

**交叉验证关注点：**
- `pct_chg`（涨跌幅）：两源应高度一致（相差 <0.01%），否则说明复权因子有误
- `volume`（成交量）：单位对齐后应完全相同（同一交易所原始数据）
- `pe_ttm` / `pb_mrq`：允许小差异（不同财报时间点），差异 >10% 需排查
- `close` 绝对值：**不可直接比较**，两源复权基准日不同是已知现象

**注意：** `data/market_baostock/` 是静态快照，迁移后不再更新。
新增股票（迁移后上市）只存在于 `data/market/`，交叉验证时跳过即可。
